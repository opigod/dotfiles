**Read this before searching the repo.** It is intentionally exhaustive: every
tracked file, what it controls, where it is deployed, line anchors for large
files, cross-file invariants, and the traps that waste agent time.

## 1. Rules and conventions for agents

1. **Check `git status` before editing.** Do not discard user work.
2. **Never commit secrets.** The live Noctalia state file
   `~/.local/state/noctalia-kwe/settings.toml` contains plugin API keys under
   `[plugin_settings.*]`. Never copy it into the repo, print it, diff it, or
   quote its secret values. If a key is needed, ask through the secret tool.
   OpenCode's `~/.config/opencode/service.json` also contains a password and is
   intentionally not tracked.
3. **Most directories here are symlinked into live config.** Editing a repo
   file changes the running desktop immediately. There is no deploy step for
   `ghostty/`, `kineticwe/`, `nvim/`, `zed-stuff/zed/`,
   `zed-stuff/vesper-blur/`, or the OpenCode links described in §3.1.
4. **Generated files are overwritten.** KineticWE `.kwe` files are written by
   Kinetic Settings and re-applied at session start; Noctalia
   `~/.local/state/noctalia-kwe/settings.toml` is written by the shell GUI;
   `kineticwe/decoration.colors` is generated by a Noctalia theme template.
   Prefer the app/export workflow for those, or warn the user that a session
   restart or theme change may overwrite hand edits.
5. **Do not run `git clean`.** It would delete the ignored live symlink
   `kineticwe/kdeglobals`.
6. **Do not invent install/build commands.** This repo has none, and the
   OpenCode plugin is loaded from TSX without a build step. Safe checks are in
   §8.
7. **Keep formats:** TOML (Noctalia, LSFG), KConfig/INI-like (`.kwe`,
   `kdeglobals`, `kglobalshortcutsrc`, `kglobalaccelrc`), JSON (output config,
   Zed theme, OpenCode config), **JSONC** (Zed settings/keymap: comments and
   trailing commas are valid), Lua (AstroNvim), TSX (OpenCode TUI plugin).
8. **Lua style:** StyLua with 120 columns, 2 spaces, Unix endings,
   double quotes, no call parentheses, collapse simple statements. Match it.
9. **Nvim plugin files are opt-in.** Most files under `nvim/lua/plugins/`
   start with `if true then return {} end` and are therefore disabled. Remove
   that guard only when the task requires activating that example.
10. **The Noctalia bar is known to glitch below 2560×1440.** The README says to
    scale it manually. Do not "fix" that by silently changing bar geometry
    unless asked.

### 3.2 Fresh-machine deployment

Run `./install.sh` from the repo root. It performs the steps below, keeps
existing targets unless `--force` is given, and backs up anything it replaces as
`<path>.bak.<timestamp>`. Interactive runs offer Firefox Nightly (§4.1);
`--yes` skips that offer. Manual equivalent:

```sh
mkdir -p ~/.config ~/.local/share/zed/extensions/installed \
  ~/.config/noctalia-kwe ~/.config/lsfg-vk ~/.config/opencode ~/opencode-plugins
ln -sfn "$PWD/ghostty" ~/.config/ghostty
ln -sfn "$PWD/kineticwe" ~/.config/kineticwe
ln -sfn "$PWD/nvim" ~/.config/nvim
ln -sfn "$PWD/zed-stuff/zed" ~/.config/zed
ln -sfn "$PWD/zed-stuff/vesper-blur" ~/.local/share/zed/extensions/installed/vesper-blur
ln -sfn "$PWD/opencode/cli.json" ~/.config/opencode/cli.json
ln -sfn "$PWD/opencode/opencode.json" ~/.config/opencode/opencode.json
ln -sfn "$PWD/opencode/plugins/current-session-cost" ~/opencode-plugins/current-session-cost
cp noctalia-full-config.toml ~/.config/noctalia-kwe/
cp kineticwe/lsfg-vk/conf.toml ~/.config/lsfg-vk/conf.toml
sudo cp -r Bibata-Modern-Ice /usr/share/icons/   # -r is required
```

Notes:

- Ensure the parent directories exist before the copy/`ln`; otherwise `ln` may
  create a link named `installed` instead of linking inside the directory.
- `cp -r Bibata-Modern-Ice /usr/share/icons/` writes to a system directory and
  normally needs root (`sudo`).
- On re-deploy, replace an existing symlink instead of nesting inside it
  (`ln -sfn` or remove the old link first). `install.sh` does this and backs up
  real directories rather than deleting them.
- Noctalia merges **every `*.toml` in `~/.config/noctalia-kwe/` alphabetically**,
  then applies `~/.local/state/noctalia-kwe/settings.toml` as an override. A
  copied full-config export therefore works as a base layer, but GUI changes
  stored in the state override can mask values from it. `install.sh` skips the
  copy when the state file already exists unless `--force` is given.
- The LSFG config is copied, not linked, to `~/.config/lsfg-vk/conf.toml`.
- OpenCode's `service.json` is machine-local and contains a password. It is
  deliberately absent from the repo; do not overwrite it when deploying.
- The `cli.json` entry for `current-session-cost` uses the live path
  `/home/opi/opencode-plugins/current-session-cost`; the `~/opencode-plugins`
  symlink must exist for the plugin to load.
- OpenCode fetches the npm plugins named in `cli.json`/`opencode.json` itself;
  only `current-session-cost` is vendored here.
- `opencode/AGENTS.md` is gitignored but linked to `~/.config/opencode/AGENTS.md`
  when present; a fresh clone will not contain it.

## 4. File-by-file reference

### 4.1 Root files

- **`README.md`** — install/deploy instructions, the repo→live map, Noctalia's
  merge/override behavior, and known issues.
- **`install.sh`** — idempotent installer. Links the config directories, copies
  the Noctalia/LSFG files and cursor theme, backs up replaced targets, skips
  the Noctalia base config when live state exists (unless `--force`), and never
  touches `service.json` or the state file. It also offers Firefox Nightly
  during an interactive run: Mozilla's tarball goes into `/opt/firefox-nightly`,
  the tree is chowned to the user so the built-in updater can write, the
  `/usr/share/applications/firefox-nightly.desktop` launcher is written, and
  `/usr/local/bin/firefox-nightly` points at it; an existing tree is maintained
  without asking, and a dangling link is repaired. `--yes` skips the offer.
  Flags: `--dry-run`, `--yes`, `--force`, `--skip-cursor`, `--skip-opencode`.
- **`.gitignore`** — ignores `AGENTS.md`, `opencode/AGENTS.md`, and
  `kineticwe/kdeglobals` (a machine-specific absolute symlink to the live
  `~/.config/kdeglobals`).
- **`noctalia-full-config.toml`** — 786-line full export of Noctalia settings
  (an old snapshot; no `config_version` field). Machine-readable section index
  in §4.5. Contains no API keys.
- **`AGENTS.md`** — this document.

### 4.9 `.githooks/pre-commit` — staged-secret guard

Shell + awk hook (no Python) that scans the index (the staged version of each
file, not the working tree) for non-empty credential assignments such as
`api_key`, `token`, `secret`, and `password`, plus known token formats (OpenAI
`sk-…`, GitHub, Slack, AWS, Google, JWT). Empty placeholders (`api_key = ""`)
and references (`"${TOKEN}"`, `"$TOKEN"`, `"env:TOKEN"`) pass. It prints the
file, line, and field name but never the value, and exits 1 on a hit. It needs
only `git` plus the usual command-line tools (`sh`, `awk`, `grep`, `xargs`,
`sed`, `mktemp`).

`install.sh` sets `core.hooksPath=.githooks`. Enable manually with
`git config core.hooksPath .githooks`; bypass a false positive once with
`git commit --no-verify`.

## 7. Gotchas / repo ↔ live drift (verified 2026-11-07)

1. **`kineticwe/kdeglobals` is an absolute symlink to `~/.config/kdeglobals`**
   and is gitignored. It exists only on this machine. Do not commit it, replace
   it with a regular file, or delete it with `git clean`.
2. **Both output-config JSONs are stale, in different ways.** Repo: two
   outputs, DP-1 2560×1440@240 CVT, HDR on, VRR `Always`, UUID `ce490dda…`,
   plus a stale virtual output. Live `~/.config/kineticweoutputconfig.json`:
   DP-1 only, same mode, but HDR off, VRR `Never`, old UUID `f33cd967…`.
   Actual runtime: DP-1 UUID `ce490dda…`, 2560×1440@240, HDR on, VRR Always,
   one output. `kscreen-doctor -o` is authoritative. Do not mass-rename UUIDs
   or trust either JSON unless the user asks.
3. **`kineticwe.kwe` contains stale tiling blocks** for UUIDs that are not in
   `[Desktops]` (`1999f8fa…`, `6f765c7a…`, `c9f56509…`, `d51b32c5…`,
   `dbba8f33…`). Empty `tiles` arrays are normal floating state.
4. **`.kwe` files are generated** by Kinetic Settings and re-applied at session
   start (`keybinds.kwe` says so explicitly). Hand edits can be overwritten by
   the Settings UI or session shutdown.
5. **Noctalia's repo config is not deployed.** `~/.config/noctalia-kwe/` is
   empty. The live overrides are
   `~/.local/state/noctalia-kwe/settings.toml` (`config_version = 16`), which
   wins over any copied full-config file. Copying the repo export there will
   not visibly restore old settings while the state override still contains
   those keys.
6. **The live Noctalia state file contains secrets.** It has API keys under
   `[plugin_settings."coder/deepseek_usage"]` and
   `[plugin_settings."noctalia/wallhaven"]`. Never copy, print, diff, or commit
   that file. The repo export contains no keys.
7. **Noctalia regenerates `kineticwe/decoration.colors`.** A theme or wallpaper
   change can overwrite it through the built-in `kineticwe` template.
8. **Noctalia merge order:** all `*.toml` in `~/.config/noctalia-kwe/` are
   merged alphabetically, then `~/.local/state/noctalia-kwe/settings.toml` is
   applied as overrides. Knowing this avoids editing the wrong layer.
9. **`ghostty/config.ghostty` is empty.** The live setup applies
   `ghostty/config` (verified via `ghostty +show-config`), even though Ghostty
   1.4's docs name `config.ghostty` as the default path. Keep edits in
   `config` unless you re-verify the load order.
10. **Zed files are JSONC.** Comments and trailing commas are valid there;
    `jq` and strict JSON parsers will reject them. Do not reformat to strict
    JSON unless the user asks.
11. **Most Nvim plugin templates are inactive.** Only
    `nvim/lua/plugins/cheatsheet.lua` is active. `community.lua`,
    `polish.lua`, and the other plugin files return early. AstroNvim defaults
    apply until a guard is removed.
12. **`lazy-lock.json` is generated.** Use `:Lazy` to update; don't hand-edit
    commit hashes.
13. **README is stale/incomplete.** It omits `-r` for the cursor copy and does
    not explain Noctalia's merge/override behavior. Use this file for facts.
14. **Known display bug:** Noctalia bar glitches below 2560×1440; the README
    says to scale manually. Don't silently change layout to "fix" it.
15. **No build/test suite exists.** Don't add one or run package managers to
    validate dotfiles. Use §8.
16. **`~/.config/opencode/service.json` contains a password.** It is
    deliberately not tracked. Never copy it into the repo, print it, or
    overwrite it with a repo file. Only `cli.json` and `opencode.json` are
    symlinked.
17. **OpenCode config is split by plugin type.** TUI-only packages go in
    `cli.json`; packages with a server entry go in `opencode.json` (their
    `./tui` loads automatically). The local `current-session-cost` is TUI-only
    and is listed in `cli.json`. It is paired with
    `-opencode.sidebar.context`; removing the plugin without removing that
    line leaves the sidebar with no Context section.
18. **The local plugin is loaded directly from TSX.** There is no build step.
    Its `cli.json` entry uses the live symlink
    `/home/opi/opencode-plugins/current-session-cost`, which must point at
    `opencode/plugins/current-session-cost`. The widget reads the `/cost`
    SQLite ledger; if the ledger path changes, update its `database` option.
19. **OpenCode's npm plugin cache is not tracked.** `~/.cache/opencode/npm/`
    is fetched from the package names in the JSON files; do not commit it.

```sh
for f in $(find nvim -name '*.lua'); do luac -p "$f" || exit 1; done
```

Notes:

- `stylua` and `selene` are **not installed**; do not install them just to
  check formatting. Follow `.stylua.toml` / `selene.toml` manually.
- `jq` is not valid for Zed `settings.json`/`keymap.json` (JSONC).
- No standard validator is available for KConfig files (`.kwe`,
  `kdeglobals`, `kglobalshortcutsrc`); do not rewrite them with an INI parser,
  because KConfig uses nested `[Section][Subsection]` syntax.
- Do not run `noctalia-kwe` or KineticWE binaries to "test" config; they are
  live GUI/session components.
- `~/.config/opencode/service.json` is not tracked; never print or dump it in
  checks.

## 10. Refresh this map when things drift

If a value or path is suspect, re-derive it cheaply:

```sh
git ls-files | sort                              # tracked files
git status --short --ignored                     # live symlink + user edits
find . -path ./.git -prune -o -type f -print | sort
grep -n '^\[' noctalia-full-config.toml          # TOML section index
grep -n '^\[' kineticwe/kglobalshortcutsrc       # shortcut section index
grep -n '^\[' kineticwe/kdeglobals               # KDE section index
kscreen-doctor -o                                # current displays
ls -la ~/.config ~/.local/state/noctalia-kwe     # live deployment
ls -la ~/.config/opencode ~/opencode-plugins     # live OpenCode links
```

Update this file when a path, deployment method, or repo↔live drift fact
changes. The goal is that the next agent does not need to rediscover it.
